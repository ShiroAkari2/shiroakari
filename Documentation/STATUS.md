# Build status
Included in this package:
- Third-person character movement and orbit camera
- Raycast interaction prompt
- Knowledge collectible and journal toggle (J)
- NPC dialogue
- One interactable rune that opens a gate
- Basic quest status display
- Position save/load (F5/F9)
- Editor utility that generates a playable prototype scene

- Full menus, settings, localization, accessibility and QA

Next production milestone: replace placeholder art, add touch controls, expand the vertical slice,
then build and test PC/Android versions.
