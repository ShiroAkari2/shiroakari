# Changelog
## v0.2
- Added inventory and a collectible Star Shard.
- Journal now stores multiple discoveries and categories.
- Quest objective display and completion snapshot.
- Save/load now includes player position, journal entries, inventory, and completed quest IDs.
- Added a clearer instruction panel and updated prototype scene builder.

## Known limitations
- No finished art/animation/audio; scene uses primitive placeholders.
- No mobile touch UI yet; keyboard/mouse controls are currently implemented.
- Save data does not yet restore inactive pickup objects or puzzle world state after reload.
- Not yet tested in Unity in this environment. Compile and play-test on the target Unity installation.


## v0.3 Web Demo
- Added a browser-playable Three.js version in `WebDemo/`.
- Added third-person movement, mouse look, running, jumping, interaction prompts, NPC dialogue, journal, inventory, quest progression, rune puzzle, gate opening, and browser-local save/load.
- Added GitHub Pages deployment instructions.
